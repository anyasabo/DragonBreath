# Hot-path calls that tools/elf_check.py accepts. Format: CALLER CALLEE COUNT.
# COUNT is the number of call sites. "--ci" fails on a call that the control
# task can reach and that is not here, and on more call sites than COUNT.
# CALLEE "(indirect)" is a call through a function pointer: the check cannot
# see its target, so each new indirect site needs a review.
# Generated from the release ELF (ESP-IDF v5.3.6) with --write-allowlist.
#
# Before you add a line or raise a count, read the call. Accept it only if one
# of these is true:
# - it runs only on a state change or on a fault (a log line, an NVS write),
# - it is a short mutex section (category "lock"),
# - it is in a source client that runs in the control task by design.
# Known debt on upstream main:
# - control_task formats and logs the status line each 2 s (log, printf, double).
# - db_klipper_mqtt_tick publishes MQTT from the control task (esp_mqtt_write).
#   On an error, esp_mqtt_abort_connection calls esp_transport_close (indirect:
#   the TLS close can write to the network).
# - pb_policy_get_snapshot uses snprintf to copy strings.
# Reviewed indirect sites:
# - wake_control_task: the control-task wake callback (xTaskNotifyGive).
# - adc_cali_raw_to_voltage: the ADC calibration scheme function.
# - esp_timer_get_time: the esp_timer clock source function.
# - esp_event_loop_run: event handlers of the MQTT client (Klipper-over-MQTT only).
